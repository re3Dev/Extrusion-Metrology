# Extrusion-Metrology
PCB with a main purpose of a low-cost, dedicated 1D metrology sensor specifically for a Klipper printer, use controlled illumination to get a high-resolution bead cross-section without running full machine vision, and automate calibration using the printer's existing motion system.
